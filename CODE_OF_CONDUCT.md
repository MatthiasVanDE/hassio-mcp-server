# Code of Conduct

## In short

Be decent to people. Assume good faith, especially across a language barrier — this is
a project about home automation, not a place anyone should have to brace themselves for.

## Expected behaviour

- Be respectful of differing viewpoints and experience levels.
- Give and accept constructive feedback gracefully.
- Focus on what is best for the project and the people using it.

## Unacceptable behaviour

Harassment, personal attacks, discriminatory language, publishing others' private
information, and other conduct that would reasonably be considered inappropriate.

## Enforcement

Report unacceptable behaviour to matthias.vanderelst@gmail.com. Reports are handled
confidentially. The maintainer may edit, hide or delete contributions, and may block a
contributor from the project, for behaviour that violates this document.
